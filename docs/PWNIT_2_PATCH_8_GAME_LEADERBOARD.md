# PwnIt 2 Patch 8 — Game + Leaderboard Shell

This patch turns the PwnIt 2 homepage into a more complete single-campaign workflow.

## Added

- A linked Number Chain Sprint skill game at `/play/pwnit-2`.
- A campaign leaderboard at `/pwnit-2/leaderboard`.
- Shared campaign data in `src/lib/pwnit2DemoCampaign.ts`.
- Cleaner user-facing copy on the homepage.
- Softer coral/peach accents while keeping the brighter PwnIt visual base.

## Not included

- No payment collection.
- No paid credit allocation.
- No redeemable voucher/discount accounting.
- No prize payout automation.
- No database migration.
