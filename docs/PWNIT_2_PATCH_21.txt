PwnIt 2 — Patch 21: Buying always allowed + dedicated How-It-Works page
=======================================================================

1) BUYING IS ALWAYS ALLOWED (#3)
   The purchase quote no longer gates buying by campaign state — you can buy a
   voucher outright at any time (funding, countdown, buy window, or after). The only
   things that block a buy are: you already won it, or you already bought it.
     • server: buildPurchaseQuote -> buyableState = true (canBuy = !won && !alreadyPurchased).
       confirmPwnit2Purchase already enforces canBuy, so this covers the API too.
     • Campaign card: now always shows Play / Buy the voucher / View leaderboard.
     • Home hero: "Buy the voucher" is always shown.
     • Status page: already reads canBuy from the server, so it follows automatically.
   Price is always voucher value minus the discount you've earned.

2) DEDICATED "HOW IT WORKS" PAGE (#2)
   The nav link used to point at the home page (so it looked like a duplicate). There
   is now a real page at /pwnit-2/how-it-works: the 4 steps, the five gauntlet games,
   and a free-play / winning / buying summary. HeaderNav now points there.
   (Also repointed the header "Terms" link to the new /legal/terms page from Patch 19.)

   Stale copy cleaned up while here: card button "Play memory game" -> "Play the gauntlet";
   home hero "memory game / Memory Sprint" -> "skill gauntlet / PwnIt Gauntlet".
